## What I work on

- **Data engineering:** streaming and batch pipelines with Kafka, Flink, Spark and ClickHouse
- **Backend:** Java and Spring Boot microservices, plus Python services with Flask
- **AI:** computer vision (YOLOv8), deep learning with TensorFlow/Keras, and LLM-powered features with Gemini, Spring AI and MCP
- **IoT and robotics:** ESP32 and MQTT systems that drive real hardware
